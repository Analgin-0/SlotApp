# SlotApp — Система управления учебными консультациями

Приложение для автоматизации записи студентов на консультации к преподавателям. Проект представляет собой клиент-серверную систему, обеспечивающую централизованное управление графиком встреч, расписанием и взаимодействие пользователей.

## ✨ Возможности

* **Ролевой доступ (RBAC):** Разграничение прав для студентов, преподавателей и администраторов.
* **Управление сессиями:** Безопасная авторизация с поддержкой нескольких активных подключений для одного пользователя.
* **Безопасность:** Зашифрованный обмен данными по протоколу TCP/TLS.
* **Кроссплатформенность:** Нативный интерфейс, реализованный на QML / Qt Quick, с поддержкой сборки под Desktop и Android.

## ⚙️ Архитектура

Система построена на архитектуре «Клиент — Сервер — СУБД»:
* **Клиент:** Реализован на Qt 6 / C++ / QML. Отвечает за интерфейс и первичную валидацию данных.
* **Сервер:** Собственный C++ TCP-сервер, обрабатывающий сетевые запросы, бизнес-логику и права доступа.
* **База данных:** Microsoft SQL Server для централизованного хранения информации.
* **Протокол:** Обмен данными осуществляется через JSON over TCP/TLS.

## 🛠 Сборка
Проект собирается с помощью CMake. В качестве среды разработки используется Qt Creator.
